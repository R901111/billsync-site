01 / Problem

記住付款，比記下消費更難。

固定支出散落在不同帳單與不同日期，有些金額固定，有些每期都會改變。 傳統記帳工具擅長記錄「已經花掉的錢」，卻不一定適合管理「接下來要付的款項」。

  • 01固定支出容易忘記繳費
  • 02不同帳單的到期日分散
  • 03水電等費用每期金額不同
  • 04未來付款提醒與歷史記帳需求不同

02 / Product flow

03 / Features

從輸入、追蹤到同步，維持清楚的責任邊界。

AI

AI 帳單解析

從圖片或 PDF 提取名稱、金額與到期日，並保留人工確認步驟，避免解析結果直接成為正式資料。

05 / Security & privacy

安全不是一句保證，而是一組可以檢查的邊界。

以下為目前已實作的公開摘要，不代表零風險、完整匿名化或任何形式的合規認證。

Backend session登入狀態由後端管理，正式環境加入 CSRF 防護。
User ownership帳單、固定支出與 Calendar credentials 依使用者隔離。
Encrypted credentialsGoogle access／refresh credentials 加密後儲存。
Explicit AI consent上傳帳單前取得同意；Responses request 明確使用 store=False。
OCR controls具備每位使用者與全站限制，以及 production kill switch。
Deployment hardening依賴套件稽核與正式環境 filesystem permission 檢查。
